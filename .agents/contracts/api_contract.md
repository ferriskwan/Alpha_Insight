# Frozen API & Schema Contract — Epic 0.1 (`Alpha_Insight`)

This contract is locked during Phase 1 of Swarm Mode. `[STREAM: BE]`, `[STREAM: FE]`, and `[STREAM: QA]` must implement and verify against these exact routes and payload shapes.

## 1. Authentication & Session Endpoints (`backend/api/v1/auth.py`)
* `GET /api/auth/env` -> `AuthEnvResponse` (`{ env: string, googleClientId: string }`)
* `POST /api/auth/google-login` -> Accepts `GoogleLoginRequest` (`{ credential?: string, mock_email?: string, mock_name?: string }`), sets `alpha_sid` cookie, persists row in `public.user_sessions`, returns `UserProfileResponse`.
* `GET /api/auth/me` -> Reads `alpha_sid` cookie from `public.user_sessions`, returns `UserProfileResponse` (`{ id, email, name, picture, status, roles }`) or `401`.
* `POST /api/auth/logout` -> Deletes session from `public.user_sessions` and clears `alpha_sid` cookie.

## 2. DataOps Ingestion Endpoints (`backend/api/v1/dataops.py`)
* `POST /api/v1/sys/init` -> Initializes `GLOBAL_TODAY` and returns `{ global_startdate: string, global_today: string }`.
* `GET /api/v1/eod/symbols?global_startdate=...` -> Returns list of `{ symbol: string, start_date: string }`.
* `POST /api/v1/eod` -> Upserts EOD OHLCV payload (`MarketSeriesPayload`).
* `GET /api/v1/fx/symbols?global_startdate=...` -> Returns list of `{ symbol: string, currency: string, start_date: string }`.
* `POST /api/v1/fx` -> Upserts FX rates (`list[FxRateItem]`).
* `GET /api/v1/tick/symbols?global_today=...` -> Returns list of `{ symbol: string, start_date: string }`.
* `POST /api/v1/tick` -> Upserts intraday 5m Tick OHLCV payload (`MarketSeriesPayload`).

## 3. Watchlist & Charting Endpoints (`backend/api/v1/watchlist.py`)
* `GET /api/watchlist/symbols` -> Returns `list[WatchlistSymbolItem]`.
* `GET /api/watchlist/data?symbol=AAPL&zoom_start=...&zoom_end=...` -> Returns `WatchlistDataResponse`:
  - `symbol`: string
  - `eodData`: `{ meta: { symbol, interval: "1d", timezone, currency }, values: [...] }`
  - `tickData`: `{ meta: { symbol, interval: "5m", timezone, currency }, values: [...] }`
  - `trades`: `list[TradeRecord]`
  - `sysDates`: `{ global_startdate, global_today }`
  - `chartScreenshot`: Base64 data URI (`data:image/png;base64,...`) generated by untouched `charting.py`.

## 4. Portfolio Endpoints (`backend/api/v1/portfolio.py`)
* `GET /api/portfolio/dashboard?currency=USD&account=All` -> Returns `PortfolioDashboardResponse`:
  - `summary`: `{ totalEquity, cashBalance, realizedPnL, unrealizedPnL, marginLoan, marginInterest, dailyInterest, totalPnL, pctReturn }`
  - `balanceMatrix`: `list[BalanceMatrixRow]`
  - `performanceSeries`: `list[PerformancePoint]`
  - `dailySummaries`: raw rows from `daily_portfolio_summary`
  - `positions`: open position rows from `position`
  - `fxRates`: `{ USD: 1.0, HKD: ..., SGD: ... }`
* `GET /api/portfolio/positions` -> Returns `list[PositionRecord]`.
* `GET /api/portfolio/trades?symbol=...` -> Returns `list[TradeRecord]`.

## 5. Transaction Editor CRUD Endpoints (`backend/api/v1/transactions.py`)
* `GET /api/transactions/watchlist`, `POST /api/transactions/watchlist`, `PUT /api/transactions/watchlist`, `DELETE /api/transactions/watchlist`
* `GET /api/transactions/trade`, `POST /api/transactions/trade`, `PUT /api/transactions/trade`, `DELETE /api/transactions/trade`
* `GET /api/transactions/capital`, `POST /api/transactions/capital`, `PUT /api/transactions/capital`, `DELETE /api/transactions/capital`
* `GET /api/transactions/sysvalue`, `POST /api/transactions/sysvalue`, `PUT /api/transactions/sysvalue`, `DELETE /api/transactions/sysvalue`

## 6. AI Stock Analysis Endpoint (`backend/api/v1/analysis.py`)
* `POST /api/analyze` -> Accepts `AnalyzeRequest`, executes Gemini or Kimi analysis, returns `AnalyzeResponse` (`{ symbol, provider, model, markdown, groundingLinks }`).

## 7. Admin & Cloud Run Job Endpoints (`backend/api/v1/admin.py`)
* `GET /api/admin/users` -> Returns list of users with roles and status.
* `POST /api/admin/users/status` -> Updates user status (`active` / `expired`).
* `POST /api/admin/users/roles` -> Assigns or updates user role (`admin` / `user`).
* `GET /api/admin/jobs` -> Returns recent `list[JobExecutionLogItem]` from `public.job_execution_log`.
* `POST /api/admin/jobs/run` -> Triggers pipeline recalculation / daily job and records execution in `public.job_execution_log`, returning `JobTriggerResponse`.
